Пример callback

using Botify;
using Botify.Attributes;

[CallbackHandler]
public class MenuCallbacks
{
    [Callback("change")]
    public async Task Change(BotifyContext context)
    {
        if (context.Chat is null || context.Message is null)
            return;

        await context.Client.EditMessageTextAsync(
            context.Chat.Id,
            context.Message.MessageId,
            "Состояние изменено.",
            cancellationToken: context.CancellationToken);
    }
}

Как это использовать

Если кнопка отправляет callback_data = "change_42", Botify возьмёт имя change и вызовет этот метод. Остальная часть строки остаётся для ваших данных.

Что хорошо знать

  • callback имя автоматически приводится к нижнему регистру;
  • пробелы в имени запрещены;
  • неизвестный callback можно обработать через UnknownCallbackHandler.
