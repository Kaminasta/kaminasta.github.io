Команды

Команды в Botify состоят из двух частей:

  • класс с атрибутом [CommandHandler];
  • методы с атрибутом [Command(...)].

Как Botify читает команду

Command-handler смотрит только на текстовые сообщения, которые начинаются с символа из CommandStartChar. По умолчанию это /.

Дальше Botify:

  1. отбрасывает первый символ;
  2. делит текст по пробелу;
  3. берёт первую часть как имя команды;
  4. удаляет @botname, если оно есть;
  5. ищет зарегистрированный метод.

Пример

using Botify;
using Botify.Attributes;

[CommandHandler]
public class CommandsHandler
{
    [Command("start", "Начать работу с ботом")]
    public async Task Start(BotifyContext context)
    {
        if (context.Chat is null)
            return;

        await context.Client.SendTextMessageAsync(
            context.Chat.Id,
            "Команда /start выполнена.",
            cancellationToken: context.CancellationToken);
    }
}

Что важно

  • Метод должен быть public.
  • Метод должен возвращать Task.
  • Метод должен принимать ровно один параметр: BotifyContext.
  • Имя команды хранится без / и автоматически приводится к нижнему регистру.
  • Если описание указано, Botify передаёт его в SetMyCommands(...).

Когда команда не найдена

Если команда неизвестна, Botify вызывает UnknownCommandHandler, если он задан в конфигурации.
