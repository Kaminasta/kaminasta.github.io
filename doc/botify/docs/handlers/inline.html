Inline-запросы

Inline-handler работает с UpdateType.InlineQuery.

Как Botify читает inline query

Botify:

  1. берёт текст InlineQuery.Query;
  2. делит его по InlineSplitChar;
  3. первую часть использует как имя inline-обработчика.

По умолчанию разделитель — пробел.

Пример

using Botify;
using Botify.Attributes;

[InlineHandler]
public class SearchInlineHandler
{
    [Inline("search")]
    public async Task Search(BotifyContext context)
    {
        if (context.InlineQuery is null)
            return;

        // Здесь можно собрать результаты и ответить через AnswerInlineQueryAsync.
    }
}

Практический смысл

Если пользователь вводит в чате что-то вроде search openai, Botify сопоставит это с inline handler-ом search.

Важно

Имя inline handler-а автоматически приводится к нижнему регистру и не может быть пустым. Неизвестный inline-запрос вызывает UnknownInlineHandler, если он задан.
