Введение

Эта документация построена вокруг того, как Botify работает в коде:

  1. сначала настраивается BotifyOptionsBuilder;
  2. затем через AddBotifyHandlers() регистрируются обработчики и валидаторы;
  3. после этого BotHostedService получает Update и маршрутизирует его в нужный handler;
  4. сам handler вызывает метод вида Task Method(BotifyContext context).

Такой формат документации полезнее, чем зеркалить дерево исходников: он показывает, как собирать бота и как писать собственные обработчики без лишних предположений.

Карта проекта

  • Configuration — токен, base URL, разделители, логирование, HTTP handler.
  • Handlers — команды, сообщения, callback, inline и платежи.
  • Advanced — валидаторы, неизвестные события и логирование.
  • Examples — готовые шаблоны файлов для старта нового бота.

Главное правило

Публичный метод-обработчик в Botify должен принимать только один параметр — BotifyContext. Это проверяется самим фреймворком при регистрации метода.
