Логирование

Botify использует LoggerService как тонкую обёртку над ILogger.

Что делает LoggerService

  • хранит ILogger, переданный в конфигурации;
  • сравнивает уровень сообщения с MinimumLogLevel;
  • пишет сообщение только если уровень достаточно высокий.

Пример использования

using Botify.Services;
using Microsoft.Extensions.Logging;

public class MyService
{
    private readonly LoggerService _logger;

    public MyService(LoggerService logger)
    {
        _logger = logger;
    }

    public void Run()
    {
        _logger.Log("Сервис запущен", LogLevel.Information);
    }
}

Настройка уровня

builder.Services.AddBotify(options =>
{
    options.UseLogger(logger, LogLevel.Information);
});

Если вы задаёте MinimumLogLevel = LogLevel.Warning, то сообщения с Debug и Information не будут записаны.

Когда логирование особенно полезно

  • при регистрации handler-ов;
  • при неизвестной команде или callback;
  • при неподдержанном типе Update;
  • при ошибках обработки.
