Валидаторы

Botify поддерживает предварительные проверки через IBotifyValidator.

Контракт

public interface IBotifyValidator
{
    Task<bool> ValidateAsync(BotifyContext context);
}

Если ValidateAsync(...) возвращает false, обработчик не вызывается.

Пример валидатора

using Botify;
using Botify.Interfaces;

public class AdminValidator : IBotifyValidator
{
    public Task<bool> ValidateAsync(BotifyContext context)
    {
        return Task.FromResult(context.User?.Id == 123456789);
    }
}

Подключение к handler-у

using Botify;
using Botify.Attributes;

[CommandHandler]
[UseValidator(typeof(AdminValidator))]
public class AdminCommands
{
    [Command("admin")]
    public async Task Admin(BotifyContext context)
    {
        if (context.Chat is null)
            return;

        await context.Client.SendTextMessageAsync(
            context.Chat.Id,
            "Доступ разрешён.",
            cancellationToken: context.CancellationToken);
    }
}

Как это работает в коде

Botify собирает UseValidatorAttribute как на уровне класса, так и на уровне метода. Перед вызовом handler-а каждый валидатор берётся из DI и вызывается по очереди.
