Конфигурация

BotifyOptionsBuilder — это объект конфигурации, который Botify создаёт внутри AddBotify(...).

Основные параметры

Параметр Назначение
BotToken Токен Telegram-бота
BaseURL Пользовательский URL для Telegram API
CommandStartChar Символ начала команды, по умолчанию /
CallbackSplitChar Разделитель callback-данных, по умолчанию _
InlineSplitChar Разделитель inline-запроса, по умолчанию пробел
Logger Сервис логирования Botify
MinimumLogLevel Минимальный уровень логирования
HttpClientHandler Пользовательский HTTP handler
UnknownCommandHandler Делегат для неизвестной команды
UnknownCallbackHandler Делегат для неизвестного callback
UnknownInlineHandler Делегат для неизвестного inline

Использование

builder.Services.AddBotify(options =>
{
    options.SetToken(token);
    options.SetBaseURL("https://api.telegram.org");
    options.UseLogger(logger, LogLevel.Information);
});

Что делает каждая настройка

SetToken(...) обязателен: без него BotClientService не создаст Telegram-клиент.

SetBaseURL(...) нужен для нестандартного Bot API сервера или прокси-сценария.

UseLogger(...) подключает логирование и задаёт минимальный уровень. Сообщения ниже этого уровня не пишутся.

SetHttpClientHandler(...) позволяет подменить HTTP handler до создания TelegramBotClient.

Неизвестные события

Если соответствующий handler не найден, Botify вызывает делегат, заданный в UnknownCommandHandler, UnknownCallbackHandler или UnknownInlineHandler.
