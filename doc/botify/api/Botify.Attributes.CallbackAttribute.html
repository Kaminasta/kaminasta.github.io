Remarks

Используется для обработки данных, передаваемых через CallbackQuery.Data.

Атрибут применяется только к методам внутри классов, помеченных атрибутом CallbackHandlerAttribute.

Пример:

[Callback("settings")]
public async Task SettingsCallback(BotifyContext context)
