Remarks

Используется для обработки сообщений, соответствующих указанному регулярному выражению.

Атрибут применяется только к методам внутри классов, помеченных атрибутом MessageHandlerAttribute.

Поддерживает:

  • Фильтрацию по типу сообщения
  • Регулярные выражения
  • Несколько типов сообщений одновременно

Пример:

[Message("^(привет|hello)$")]
public async Task HelloMessage(BotifyContext context)
